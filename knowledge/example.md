# Example knowledge document

This sample document verifies that the voice assistant can retrieve information from Markdown. Replace it or add your own documents.

## Grounded answers

When answering a question about a connected document, identify the relevant passage, explain what it says in plain language, and distinguish direct statements from inference. If no relevant passage is returned, say that the connected knowledge base did not provide an answer rather than inventing a fact.

## Example fact

The demonstration project's Markdown knowledge files live in the `knowledge/` directory. The server endpoint searches Markdown files in that directory and its subdirectories and returns up to five matching passages.
