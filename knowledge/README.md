# Knowledge base

Put Markdown (`.md`) documents in this folder or in subfolders. The Hume voice assistant can search them through `/api/knowledge-search` when the `search_knowledge` tool is enabled in the Hume configuration.

- Use focused paragraphs and clear headings.
- Keep source titles, URLs, dates, and section numbers in the text.
- Do not put passwords, API keys, or private credentials here.
- The included search is a simple keyword baseline. For a large corpus, replace it with a semantic retrieval pipeline and a vector database.

Add your documents in this folder and push them to GitHub so they are included in the Vercel deployment.
